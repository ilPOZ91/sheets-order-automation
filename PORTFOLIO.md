**Title** (max ~70 characters)
Google Sheets automation: data cleanup, sales report, payment reminders

**Role**
Google Apps Script developer

**Description**
Demo project (not client work) built around a very common problem: an order list kept in a shared spreadsheet, full of inconsistent names, mixed date and number formats, duplicates and forgotten unpaid invoices.

The Google Apps Script tool adds an "Automations" menu to the sheet:
- Cleans and validates every row (names, emails, phones, dates, European number formats) without ever overwriting invalid data: problems are listed and highlighted
- Flags exact and possible duplicates
- Builds a sales report with monthly chart, product breakdown and top customers
- Emails polite payment reminders for overdue invoices, with preview mode, confirmation, daily-quota handling and a 7-day cooldown
- Runs automatically every day

The core logic is unit-tested (12 tests, including an end-to-end run on demo data), and the whole tool was tested in a live Google Sheet.
